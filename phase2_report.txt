Canonical Scene Integration Architecture:

    Canonical Scene
         ↓
    Zustand Scene State (store.scene)
         ↓
    Existing Design UI

The canonical Scene is the authoritative representation of design-scene data.
The Zustand store's existing fields (objects, shapes3D, constraints, materials, layers, simulationSettings)
remain as the operational state, now also accessible via store.scene.*.
UI state (selection, tools, camera, playback) remains separately managed.
No two independently mutable sources of truth exist.

Authoritative Scene State:
[location: web/src/store/useStore.js - store.scene property]

Editor State (separate from Scene):
- selectedIds: selected 2D object IDs
- selected3DIds: selected 3D shape IDs
- activeTool: current tool (select, create_circle, etc.)
- is3DView: toggle between 2D/3D view
- activeWorkspace: 'design' or 'simulate'
- camera: viewport camera state
- isPlaying, simTime, currentFrameIndex: simulation runtime state
All remain as editor/runtime state, NOT in canonical Scene.

Runtime Simulation State (separate from Scene):
- simTime, simulationState, simulationFrames, isPlaying, fps
All remain as runtime state, NOT in canonical Scene.

Scene Data (now in canonical form via store.scene):
- metadata: { id, name, schemaVersion, createdAt, updatedAt }
- objects: SceneObjectDef[] - 2D design objects
- materials: MaterialDef[] - material definitions with density, friction, restitution
- constraints: ConstraintDef[] - physics constraints
- forces: ForceDef[] - forces acting on objects
- layers: LayerDef[] - scene layers
- initialConditions: InitialConditionDef - initial position/velocity
- environment: { gravity, coordinateConvention }
- simulationSettings: SimulationSettingsDef - physics simulation parameters

Scene Actions (existing, now compatible with canonical scene):
- addCADObject() - adds 2D design object to objects array and scene.objects
- addShape3D() - adds 3D physics shape to shapes3D array and scene.objects
- setObjects() - replaces objects array
- setConstraints() - replaces constraints array
- setMaterials() - materials accessible via scene.materials
- setLayers() - replaces layers array
- setActiveLayerId() - active layer ID
- applyMaterial() - applies material to objects (updates material_id, restitution, friction)
- setSimulationSettings() - updates simulation settings (also updates scene.simulationSettings)
- addConstraint(), updateConstraint(), removeConstraint() - constraint management
- deleteObjects() - deletes selected objects from both store and scene
- duplicateObjects(), mirrorObjects(), offsetObject(), arrayObjects() - object duplication/mirroring/offsetting
- groupObjects(), ungroupObjects() - grouping functionality
- clearDesign() - resets store AND canonical scene to default state
